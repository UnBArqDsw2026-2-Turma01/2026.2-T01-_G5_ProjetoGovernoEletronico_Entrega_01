No NFR Framework, as interdependências entre requisitos não funcionais são representadas graficamente por meio de um Softgoal Interdependency Graph (SIG). Nesse grafo, os softgoals podem ser refinados em elementos mais específicos e relacionados por contribuições positivas ou negativas, possibilitando a análise qualitativa dos efeitos das alternativas de projeto sobre os requisitos não funcionais (CHUNG et al., 2000). <!-- talvez esteja redundante daqui... --> Chung et al. também afirmam que o SIG “representa e armazena os passos e raciocínios do projeto” de NFR, ou seja, serve como histórico do desenvolvimento. Além disso, esse framework apoia a tomada de decisão sendo possível atribuir pesos aos softgoals de topo e propagar avaliações através do grafo.<!-- ...até aqui--> Com isso, as decisões de design podem ser justificadas quantitativamente, um benefício para a análise da Usabilidade do “Meu SUS Digital”.

## Legenda do SIG

| Categoria                                    | Símbolo / Elemento Visual | Texto Original                | Tradução (Português)                      |
| :------------------------------------------- | :------------------------ | :---------------------------- | :---------------------------------------- |
| **Softgoals**                                | Nuvem com borda fina      | NFR Softgoal                  | Softgoal de NFR (Requisito Não-Funcional) |
|                                              | Nuvem com borda grossa    | Operationalizing Method       | Método de Operacionalização               |
|                                              | Nuvem com borda tracejada | Claim                         | Argumento (ou Afirmação)                  |
|                                              | `!`                       | Critical                      | Crítico                                   |
|                                              | `✓`                       | Accepted                      | Aceito                                    |
|                                              | `X`                       | Rejected                      | Rejeitado                                 |
| **Interdependência** <br>_(Interdependency)_ | Seta com linha contínua   | Implicity                     | Implícito                                 |
|                                              | Seta com linha tracejada  | Explicity                     | Explícito                                 |
|                                              | `++`                      | Strongly positive satisficing | Satisfação fortemente positiva            |
|                                              | `+`                       | Positive satisficing          | Satisfação positiva                       |
|                                              | `-`                       | Negative satisficing          | Satisfação negativa                       |
|                                              | `--`                      | Strongly Negative satisficing | Satisfação fortemente negativa            |
