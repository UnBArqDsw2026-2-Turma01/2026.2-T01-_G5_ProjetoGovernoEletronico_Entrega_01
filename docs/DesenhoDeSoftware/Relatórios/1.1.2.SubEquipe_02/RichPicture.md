### Metodologia do Foco_01

Para esta versão do artefato, o foco foi na expansão dos fluxos de interação dos atores. Especificamente, o trabalho incluiu a alteração do fluxo para representar uma nova rota de navegação sem login, além de um aprofundamento na etapa de autenticação via token.
