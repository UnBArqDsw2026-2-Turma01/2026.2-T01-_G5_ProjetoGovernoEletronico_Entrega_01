# Iniciativas Extras

## 1. Introdução

Este documento tem como objetivo registrar e centralizar as **Iniciativas Extras** desenvolvidas pela equipe ao longo do projeto. Essas iniciativas englobam guias, padronizações, atas e ferramentas auxiliares criadas para enriquecer o processo de desenvolvimento e documentação.
