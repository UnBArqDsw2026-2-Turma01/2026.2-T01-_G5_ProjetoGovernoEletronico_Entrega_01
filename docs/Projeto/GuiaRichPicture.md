# Guia para Criação de Rich Picture

## 1. O que é um Rich Picture?

O **Rich Picture** é um representação visual utilizada para compreender uma situação, problema ou contexto de trabalho de forma ampla. Segundo **Monk e Howard (1998)**, ele permite reunir em uma única representação os diferentes elementos envolvidos em uma situação e as relações entre eles.

0 Rich Picture pode representar:

- **Atores:** pessoas, grupos ou organizações envolvidos;
- **Sistemas e entidades:** softwares, locais, objetos e serviços relevantes;
- **Relações:** comunicação, troca de informações, dependências e fluxos;
- **Preocupações:** dificuldades, dúvidas e percepções dos envolvidos;
- **Conflitos:** situações em que existem interesses ou problemas entre elementos;
- **Fronteiras:** limites entre o sistema analisado e seu ambiente.

Não existe uma simbologia obrigatória. Podem ser utilizados **ícones, desenhos, textos, setas, balões de pensamento e outros símbolos**, desde que contribuam para representar a situação.

### Como construir um Rich Picture?

Antes de começar, procure identificar:

> **Quem participa da situação? O que está acontecendo? Como os elementos se relacionam? Quais são os problemas, conflitos e preocupações?**

Comece posicionando os principais atores e elementos. Depois, represente suas relações e, por fim, destaque os problemas e preocupações encontrados.

O Rich Picture **não deve ser tratada como um fluxograma**. As setas podem representar fluxos, mas o objetivo principal é apresentar uma **visão geral do contexto**, e não apenas uma sequência de etapas.

## 2. Convenções visuais

As convenções podem ser definidas pela própria equipe. Um exemplo:

| Elemento | Significado |
| --- | --- |
| **Seta contínua** | Relação ou fluxo principal |
| **Seta tracejada** | Relação indireta ou secundária |
| **Balão de pensamento** | Preocupação ou percepção de um ator |
| **Espadas cruzadas** | Conflito ou dificuldade |
| **Fronteira tracejada** | Limite do sistema analisado |

O mais importante é manter a **consistência**: se um símbolo possui determinado significado, ele deve ser utilizado dessa mesma maneira em toda a Rich Picture.

## 3. Criando no Cloudairy

O [Cloudairy](https://cloudairy.com/app) foi uma das ferramentas indicadas para a criação de Rich Pictures.

- Crie um **Blank Whiteboard**;
- Utilize **Icons** para inserir atores e entidades;
- Use **Text (T)** para identificar os elementos;
- Utilize **Arrow/Connector (C)** para representar relações;
- Em **Shapes > Callouts**, crie balões de pensamento;
- Utilize **Rectangle** com borda tracejada para representar uma fronteira, quando necessário.

### Dica

Um bom Rich Picture não é necessariamente o mais detalhado e sim aquele que permite que outra pessoa **olhe para a representação e compreenda rapidamente quem está envolvido, como os elementos se relacionam e onde estão os principais problemas ou preocupações**.
